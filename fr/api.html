Référence API DoQuill

Tout ce dont vous avez besoin pour intégrer vos applications à la plateforme ERP DoQuill

Obtenir un accès API

Développez sur DoQuill

L'API REST de DoQuill offre aux développeurs un accès programmatique à toute la puissance de notre plateforme ERP. Que vous construisiez des intégrations sur mesure, automatisiez des flux de travail ou synchronisiez des données avec des outils externes, l'API couvre chaque module — de la Finance et des RH au CRM et aux Stocks.

URL de base
BASE https://app.doquill.io

Tous les points de terminaison nécessitent un jeton Bearer obtenu via POST /api/login. Transmettez-le dans l'en-tête Authorization à chaque requête.

Plus de 10 modules Couverture API complète
REST / JSON Standard du secteur
Jeton Bearer Authentification sécurisée
200 / 401 / 422 Codes de réponse clairs

Authentification

Obtenez un jeton Bearer, maintenez-le à jour et révoquez-le une fois terminé. Tous les autres points de terminaison reposent sur ces trois appels.

POST /api/login

Connexion

En-têtes

Accept: application/json

Paramètres du corps

email, password

Succès

200 OK — objet utilisateur + jeton

Erreurs

422 Validation, 400 Identifiants incorrects

POST /api/refresh

Rafraîchissement du jeton

En-têtes

Accept + Authorization: Bearer <token>

Succès

200 OK — nouveau jeton renvoyé

Erreurs

401 Non autorisé

POST /api/logout

Déconnexion

En-têtes

Accept + Authorization: Bearer <token>

Succès

200 OK — « Déconnexion réussie »

Erreurs

401 Non autorisé

Format de réponse

Chaque réponse est au format JSON et suit une structure prévisible. Vérifiez le code de statut de premier niveau, puis lisez le corps.

200 OK — Succès
{
  "success": true,
  "message": "Données récupérées avec succès.",
  "data": { ... }
}
422 — Erreur de validation
{
  "success": false,
  "message": "Erreur de validation",
  "errors": {
    "field": ["Le champ est requis."]
  }
}
401 — Non autorisé
{
  "message": "Non authentifié."
}
