DoQuill API Reference

Everything you need to integrate your applications with the DoQuill ERP platform

Get API Access

Build on DoQuill

The DoQuill REST API gives developers programmatic access to the full power of our ERP platform. Whether you're building custom integrations, automating workflows, or syncing data with external tools, the API covers every module — from Finance and HRM to CRM and Inventory.

Base URL
BASE https://app.doquill.io

All endpoints require a Bearer token obtained via POST /api/login. Pass it in the Authorization header on every request.

10+ Modules Full API coverage
REST / JSON Industry standard
Bearer Token Secure auth
200 / 401 / 422 Clear response codes

Authentication

Obtain a Bearer token, keep it fresh, and revoke it when you're done. Every other endpoint builds on these three calls.

POST /api/login

Login

Headers

Accept: application/json

Body params

email, password

Success

200 OK — user object + token

Errors

422 Validation, 400 Bad credentials

POST /api/refresh

Token Refresh

Headers

Accept + Authorization: Bearer <token>

Success

200 OK — new token returned

Errors

401 Unauthorized

POST /api/logout

Logout

Headers

Accept + Authorization: Bearer <token>

Success

200 OK — "Logged out successfully"

Errors

401 Unauthorized

Response Format

Every response is JSON and follows a predictable shape. Check the top-level status code, then read the body.

200 OK — Success
{
  "success": true,
  "message": "Data retrieved successfully.",
  "data": { ... }
}
422 — Validation Error
{
  "success": false,
  "message": "Validation error",
  "errors": {
    "field": ["The field is required."]
  }
}
401 — Unauthorized
{
  "message": "Unauthenticated."
}
